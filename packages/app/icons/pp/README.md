# PP brand assets

`logo-authentic.png` and `logo-authentic-zh.png` are unchanged copies of the
original header logos served by https://principleofprocrastination.com/en/ and
https://principleofprocrastination.com/zh/ (website `services/web-next/public`).

`mark.svg` embeds the English original unchanged and uses an SVG viewport to
show only its symbol for compact UI and browser icons. It does not redraw the
logo. The app uses the complete Chinese lockup for Chinese locales and the
English lockup otherwise. Dark appearance inverts the asset through CSS.
